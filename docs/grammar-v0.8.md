# WOLN grammar

**V0.8 Draft**

## Canonical writing and compatible input

Canonical WOLN is the simplified writing style described here. A canonical sentence can use full English vocabulary or a context-appropriate short form. Compatible input also includes standard English sentences with articles, verb inflections and plural nouns. A reader or converter should accept both and preserve the intended meaning.

The examples use the starter lexicon's written candidates to illustrate optional forms. Each corresponding full form is valid.

## Core rules

| Topic | Canonical WOLN | Example |
| --- | --- | --- |
| Word order | Keep the familiar English subject–verb–object order in statements with an object. | `I send photo.` |
| Verb tense | Use the base verb form. Express relevant time with a word, phrase or date. | `I send photo yday.` / `I send photo tmr.` |
| Subject agreement | Use the same base verb across subjects, including third-person singular. | `I send photo.` / `She send photo.` |
| Noun number | Use a number plus the singular noun when the count is explicit. WOLN does not require plural marking, and compatible input may retain standard-English plurals. | `1 app`, `2 app`, `3 file` |
| Articles | Omit `a`, `an` and `the` in ordinary canonical writing. State any quantity or reference that matters. | `I use app.` |
| Specific reference | Use `this` or `that` when it matches the intended object. Use a name or other explicit reference when needed. | `I use this app.` |

## Preserve information in conversion

- If standard English expresses time only through tense, carry over the meaning with a time phrase when needed. For example, `I sent this file.` can become `I send this file earlier.` Use a specific date or words such as `yday` only when the source supplies that information.
- Keep negation, modality, conditions, numbers and names. For example, `She cannot send this file today.` can become `She cannot send this file today.`
- Preserve a source reference whose specificity matters. If the context cannot identify the object, ask for context or retain the standard-English wording.
- Preserve an unspecified quantity as unspecified. Add an explicit number only when it comes from the source.

V0.8 describes the baseline for everyday sentences. Questions, complex clause structure and further simplifications can use familiar English where the draft gives no specific rule. See the [examples](../examples/english-woln-comparison.md).

## 繁體中文補充

典型寫法可用動詞原形、時間詞和「數字＋單數名詞」。遇到日期、數量、否定或指涉不明時，以保留原意為優先。
