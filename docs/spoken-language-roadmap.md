# Spoken-language roadmap

**V0.8 Draft**

WOLN develops writing first and investigates shorter standard readings as a separate research track. Begin with recognizable English-like pronunciation. Optional sound simplification is a research subject when it helps speakers and preserves intelligibility. Readers may use the familiar full-English pronunciation while candidate short readings are being studied.

## Proposed testing sequence

1. Record the exact proposed reading, the baseline, example utterances and any potentially confusable words. Use an audio example or IPA where useful.
2. Compare comprehension across listeners with different first languages. Record comprehension, ambiguity and speaking time. Try the form in isolation and in ordinary sentences.
3. Run automatic speech recognition (ASR) separately using the same utterances and ordinary English baselines. Record the engine, version, locale and observed transcriptions. Test each newly proposed reading empirically.
4. Publish aggregate results and review decisions. Consider standardizing a reading only after evidence and community review support it.

The draft has no standardized short pronunciation. The written candidates can be used independently of the spoken research.
