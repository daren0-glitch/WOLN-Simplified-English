# Short words

**V0.8 Draft**

Written forms come first. A short form should retain a recognizable connection to familiar English, fit the audience and make sense in the sentence. The full English word is always accepted, including alongside short forms in the same sentence.

The [starter lexicon](../lexicon/core-words.csv) records ten written candidates. `CANDIDATE` means a form is available for illustration and community review, with no claim of global acceptance. A term can be widely familiar in some audiences and still be a candidate for inclusion in this specification.

| Full English | Candidate | Usage |
| --- | --- | --- |
| tomorrow | `tmr` | `I send photo tmr.` |
| yesterday | `yday` | `She send file yday.` |
| information | `info` | `I need more info.` |
| application | `app` | `I use this app.` |
| technology | `tech` | `We use new tech.` |
| message | `msg` | `I send msg today.` |
| people | `ppl` | `Ppl use this app.` |
| please | `pls` | `Pls send this file.` |
| photograph | `photo` | `I share this photo.` |
| artificial intelligence | `AI` | `We use AI to organize 3 photo file.` |

Read abbreviations in context. For example, `app` in the starter list means a software application. Use `application form` or the full term for other meanings. Use `yday` or `yesterday` for the previous day. The abbreviation `YTD` also means Year to Date and is excluded as a form for `yesterday`.

A written form's inclusion in the table carries no spoken validation. See the [spoken roadmap](spoken-language-roadmap.md).
