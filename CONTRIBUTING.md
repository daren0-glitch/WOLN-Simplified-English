# Contributing to WOLN

English is the primary language of the specification and review. Traditional Chinese explanations and examples are welcome as supplementary material.

## Propose a change

1. Open or reuse a GitHub Issue. Include the relevant V0.8 rule or lexicon row, a proposed revision, before-and-after examples and the reason it improves communication.
2. Describe any ambiguity, alternate meanings or differences by region or audience. For a short word, include a full English fallback and its proposed status. For a spoken form, record the written form, proposed reading and evidence separately.
3. For a substantial change, create a separate feature branch and open a pull request linked to the Issue. Keep the grammar, examples, lexicon and changelog consistent where the change affects them.
4. Leave the proposal open for review and preserve the outcome in the linked Issue or PR. Changes to core rules require explicit approval. Keep unreviewed proposals out of `main`.

For language tests, include the sentences, evaluation method, audience or ASR configuration, and results. Use public examples without personal information or credentials.

## 繁體中文補充

提出修訂時，請附上原句、建議寫法及可能的歧義。重要變更使用獨立分支與 PR，並記錄審查決定。
