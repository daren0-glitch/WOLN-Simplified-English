# WOLN — Simplified English

Use the [V0.8 grammar](../../docs/grammar-v0.8.md) and [core lexicon](../../lexicon/core-words.csv) from this repository.

## English to WOLN

1. Identify the subject, action, object, time, count, negation, modality and specific references in the source.
2. Use familiar English and keep its recognizable word order. Use base verbs, explicit time and singular counted nouns. Omit articles where the intended reference is clear.
3. Use a listed written candidate when requested or clearly useful to the audience. Use the full English form when the short form is ambiguous.
4. Return the converted text. Add a short note when a meaningful ambiguity remains or when the user asks for the rules.

## WOLN to English and grammar guidance

- Expand candidate short forms according to context. Restore ordinary English articles, tense and agreement when their meaning is inferable.
- Preserve unspecified quantities and times. Ask a focused question if a missing detail is essential.
- When explaining a rule, give a paired example. Identify a written candidate as a draft proposal when discussing its status.
- Treat proposed short pronunciations as research. See the [spoken-language roadmap](../../docs/spoken-language-roadmap.md).

Example conversion from “She sent three files yesterday” to “She send 3 file yday.”
