# English–WOLN comparison

**V0.8 Draft**

| Standard English | Canonical WOLN | What carries the meaning |
| --- | --- | --- |
| She sends that message every day. | She send that msg every day. | The subject, reference and frequency remain clear. |
| Yesterday I uploaded three files. | I upload 3 file yday. | `yday` gives the time. `3` gives the exact count. |
| I will send the photo tomorrow. | I send photo tmr. | The date context comes from `tmr`. The shared conversation supplies which photo. |
| I want to use this application. | I want to use this app. | `this` keeps the original reference. |
| I cannot share that photograph today. | I cannot share that photo today. | The negation, reference and time remain explicit. |
| Please send more information. | Please send more info. | Full English words and written candidates can appear together. |
| Please send more information. | Please send more information. | The sentence already fits the draft without abbreviations. |

Question formation and further shortcuts are open to review. See the [grammar](../docs/grammar-v0.8.md) and [conversations](basic-conversations.md).
