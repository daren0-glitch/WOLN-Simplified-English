## Send files

| Speaker | Standard English | Canonical WOLN |
| --- | --- | --- |
| A | Can you send these three files today? | Can you send these 3 file today? |
| B | I can send one file today and two files tomorrow. | I can send 1 file today and 2 file tmr. |
| A | Please send me that message too. | Pls send me that msg too. |

## Ask about a photo

| Speaker | Standard English | Canonical WOLN |
| --- | --- | --- |
| A | Did she share this photo yesterday? | She share this photo yday? |
| B | Yes, she shared this photo yesterday. | Yes, she share this photo yday. |

The short question illustrates conversational wording. A compatible English question such as `Did she share this photo yesterday?` is also valid input.
